# Modelos de conteúdo

Os diretórios desta pasta são pontos de partida para finalidades específicas.
Eles não definem novas classes e não duplicam a identidade visual.

Todos os documentos institucionais usam a classe genérica `ieeeufgcs`. Cada
modelo seleciona opções da classe, fornece metadados de exemplo e sugere uma
estrutura de conteúdo que pode ser alterada conforme a necessidade.

- `work-plan`: plano de trabalho, proposta institucional ou pedido de
  aprovação com objetivos, etapas, responsabilidades e decisões solicitadas.

Modelos futuros para atas, registros de decisão, relatórios e materiais de
divulgação devem seguir a mesma separação entre apresentação e conteúdo.
