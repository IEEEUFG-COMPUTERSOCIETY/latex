# Packaged artwork

These files are normalized PDF copies of official artwork supplied with the
project. Filenames were changed only to provide stable, space-free package
paths.

| Packaged file | Supplied source |
|---|---|
| `ieeeufgcs-cs-logo-orange.pdf` | `Logo/IEEE-CS_LogoTM-orange.eps` |
| `ieeeufgcs-cs-logo-black.pdf` | `Logo/IEEE-CS_LogoTM-black.eps` |
| `ieeeufgcs-cs-logo-white.pdf` | `Logo/IEEE-CS_LogoTM-white.eps` |
| `ieeeufgcs-cs-logo-orange-white.pdf` | `Logo/IEEE-CS_LogoTM-orange bug-white text.eps` |
| `ieeeufgcs-master-brand-blue.pdf` | `MB Lockups/.../IEEE ComputerSoc_MB Blue Lockup CMYK.pdf` |
| `ieeeufgcs-master-brand-black.pdf` | `MB Lockups/.../IEEE ComputerSoc_MB Black Lockup CMYK.pdf` |
| `ieeeufgcs-master-brand-white.pdf` | `MB Lockups/.../IEEE ComputerSoc_MB Lockup WHITE CMYK.eps` |

EPS sources were converted with `epstopdf`; the supplied CMYK PDFs were copied
without content changes. Trademark and usage restrictions remain those of IEEE
and the IEEE Computer Society.
